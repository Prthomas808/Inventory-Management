# Inventory Management Application
A simple Inventory Management System built with Django 5.2.6 and Python 3.13.3, designed to help you streamline and optimize your product management. This app provides a clean interface to create, read, update, and delete products, with a responsive design using Tailwind CSS.

## Features

Dashboard / Home Page: Quick access to all products.

Product Management (CRUD):

Add new products with name, SKU, price, and quantity.

View all products in a table with details.

Delete products with confirmation.

Update products (form reuse is supported).

Simple UI: Built with Tailwind CSS for clean, responsive design.

Default Database: Uses SQLite (Django default).

# Technologies Used

Backend: Python, Django 5.2.6

Frontend: HTML, Tailwind CSS

Database: SQLite (default Django database)
